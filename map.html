コードの地図

Giftia の「画面のここ」が「コードのどこ」なのかを、地図にしました。コードの中身はここには載せていません。行のリンクを押すと GitHub（非公開。班のメンバーと講師だけ）のその行が開きます。商品は説明用の例です。

おすすめの読む順番

  1. 画面の地図で、画面を触りながら「メモ帳（状態）」がどう変わるかを見る
  2. 動きの地図で、検索ボタンから DB までの12ステップを最後まで進める
  3. 変える地図で、「変えたいこと」から変える1行を探す。発展2の前にもう一度
  4. データの地図で、DB の列が画面のどこに出るかを線でたどる
  5. ファイルの地図の「1行ずつ読む」で、GitHub のコードと並べて読む
  6. ことばの地図のクイズで、ここまでを確かめる

行のリンクが 404 になるとき

giftia は非公開なので、GitHub にログインしていないブラウザで開くと「404（ページがない）」と出ます。

  • Safari で一度 github.com にログインしてから、もう一度リンクを押す（いちばん確実）
  • GitHub アプリで開くときは、リンクを長押し →「“GitHub”で開く」
  • 班のメンバー（Collaborator）として招待を受けていないアカウントでは開けない

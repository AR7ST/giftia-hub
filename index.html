🚀 最初だけ

自分の PC で動かす

clone → .env をコピー → API（8000番）と画面（3000番）を起動。くわしくは README の3章。

README を読む →

スマホの Claude Code とつなぐ

  1. claude.ai/connect-github で GitHub を許可
  2. Claude GitHub App に giftia・giftia-hub を入れる
  3. Code → 新規 → giftia を選ぶ

🗼 改善の流れ

  1. Issue を作る：Projects で「Giftia 改善ボード」を選ぶ（やること）
  2. 担当を決めて始める：Assignees に自分（作業中）
  3. ブランチで変える：main を pull → ブランチ → 変更・確認
  4. PR を出す：何を／なぜ／確認手順 と Closes #番号（確認待ち）
  5. 本人以外が Approve：手元で動かしてから
  6. merge：Issue は自動で閉じる（完了）
  7. 全員で再現：pull して「再現 OK」。このページの改善ログに1行

💡 ナレッジ

ルールの要点

  • main に直接 push しない。変更はブランチ＋PR
  • 作業の前に git pull
  • 1つの PR には1つの変更だけ
  • Approve は本人以外。Approve が付いてから merge
  • .env の中身は、GitHub・Slack・生成 AI に貼らない
